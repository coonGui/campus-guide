# 오늘 어디로 갈까? : 공강 시간 캠퍼스 공간 안내 웹앱

캠퍼스가 낯선 학생이 공강에 갈 곳을 목적별 추천·층 도면·360° 사진으로 찾는 웹앱입니다.
명지전문대 공간정보 캡스톤디자인 3조 에리지(EveryGIS) · AI-ON 2026 중간 제출판(9단계 12차)

## 바로 써 보기
- 웹앱: https://coongui.github.io/campus-guide/
- 시연 영상: [https://youtu.be/3-CJeJLVS4g]
- 설치 없이 컴퓨터 Chrome이나 휴대폰 브라우저에서 열면 됩니다.

## 왜 만들었나
신입생·외국인 유학생·복학생처럼 캠퍼스가 낯선 학생, 그리고 늘 쓰던 곳만 쓰는 재학생은
학교에 휴게실·학습공간·카페가 있어도 위치와 이용 방법을 몰라 그냥 지나칩니다.
이 앱은 "지금 이럴 땐 여기를 이렇게 쓰면 된다"를 한 화면에서 알려 줍니다.

## 주요 기능
1. 상황별 추천: 질문 4개(할 일·세부 상황·출발 위치·시간)에 답하면 지금 갈 만한 곳과 이유를 보여 줍니다. 더 자세히 고르려면 질문 9개로 바꿀 수 있습니다.
2. 지도 → 건물 → 층 → 장소: 사진 지도(정사영상) 또는 그림 지도에서 건물을 누르면 층을 고르고, 층 도면에서 장소를 누르면 시설 정보가 열립니다.
3. 층 도면 41장: 학교 층 도면을 SVG로 다시 그려 휴대폰에서 확대해도 또렷합니다.
4. 360° 사진 14장: 가기 전에 장소 안을 둘러볼 수 있습니다(사람 얼굴은 흐림 처리).
5. 경로 미리보기: 출발 층 도면 → 캠퍼스 지도 → 도착 층 도면 순서로 가는 길을 보여 줍니다.
6. 이용 정보: 요일별 운영 시간, 이용 조건(예: 키오스크 좌석 발권), 좌석 수, 콘센트 등.
7. 다크 모드와 휴대폰 화면을 지원합니다.

## 1분 사용법
1. 첫 화면에서 '상황별 추천'을 누르고 질문 4개에 답합니다.
2. 결과 카드를 누르면 장소 정보가 열립니다. '360° 사진 보기'로 안을 둘러보고, ▶로 가는 길을 봅니다.
3. 위쪽 '공간 둘러보기'에서 건물과 층을 직접 골라 볼 수도 있습니다.

※ 추천은 운영 시간을 따르므로 밤에는 결과가 비어 있을 수 있습니다.
   이때는 위쪽 '출발 위치·시연 조건'을 펼쳐 '추천 기준 시각'을 낮 시간(예: 오늘 12:30)으로 바꿔 보세요.

## 데이터와 출처
- 시설 정보: 팀이 직접 현장 조사한 캠퍼스 시설 24곳(엑셀 시설 DB를 변환 도구로 앱 데이터로 바꿈)
- 사진 지도: 국토지리정보원 정사영상(2025년 촬영)
- 그림 지도: © OpenStreetMap 기여자 자료를 정사영상 자리에 맞춰 그림
- 층 도면: 학교 층 안내 도면을 바탕으로 팀이 SVG로 다시 그림
- 360° 사진: 팀 촬영

## 지금 판의 한계
- 경로 이동 시간은 실측 전 가정값입니다. 2단계에 시연 경로를 실측해 실제 값으로 바꿉니다.
- 서버 없이 HTML 파일 하나로 동작해, 조사 자료를 고치면 파일을 다시 만들어 올려야 합니다.
- 운영 시간·이용 조건은 조사 시점 기준이라 실제와 다를 수 있습니다.
- 도면이 없는 건물·층은 장소 목록만 보여 줍니다.
- 메뉴의 '온라인 조사·학습실'은 외부 시범 사이트이며, 2단계에 웹앱 안으로 옮길 예정입니다.

## 어떻게 만들었나 (AI 활용)
- 초기: ChatGPT로 첫 웹앱과 온라인 조사·학습실 시범 사이트를 빠르게 만들어 방향을 잡았습니다.
- 이후: Claude에 작업 지침서(결정·데이터 규칙·금지 사항)를 주고, 한 기능씩 '지시 → 결과 → 검수 → 수정'을 되풀이해 9단계 12차 판까지 쌓았습니다.
- AI가 맡은 일: 엑셀 → 앱 데이터 변환 도구(팀 확인 값과 다른 칸 알림), 도면 41장 SVG 변환, 정사영상 지도, 360° 사진 얼굴 흐림, 자동 검사
- 팀이 맡은 일: 현장 조사·사진 촬영, 고칠 값 결정, 휴대폰으로 직접 써 보며 검수
- 12차 판은 자동 검사 304개를 통과했습니다.

## 2단계 계획
- 시설 DB를 DB 서버로 옮기고 서버 도메인에 올려, 조사 자료를 고치면 바로 반영
- 추천 카드 좋아요·싫어요와 개인이 드러나지 않는 시설별 통계
- 장소마다 학교 프로그램 정보 함께 보여 주기
- 시연 경로 실측으로 이동 시간을 실제 값으로
- 영어와 동남아 언어 1개 메뉴
- 포털 로그인은 학교와 협의해 가능성 확인
